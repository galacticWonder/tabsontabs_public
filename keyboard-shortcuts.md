# Keyboard Shortcuts for Version 2.0

| Shortcut | Action |
| --- | --- |
| Slash (or Ctrl+Alt+S) | Go to the search box |
| Escape | Clear search |
| Left Arrow | Scroll the windows left |
| Right Arrow | Scroll the windows right |
| Ctrl+Alt+T | Go to top within the window |
| Ctrl+Alt+B | Go to the bottom within the window |
| Ctrl+Left Arrow | Cycle left between filters |
| Ctrl+Right Arrow | Cycle right between filters |
| Ctrl+Alt+B | Toggle dark mode |
