# TabsOnTabs Release Notes

## Version 2.0
Release date: 03-23-2026

TabsOnTabs now works across 3 major browsers: Edge, Chrome & Firefox!<br>
Tons of new features & bug fixes!

### New features
- [Issue #1](https://github.com/galacticWonder/tabsontabs_public/issues/1): Added browser support for Edge & Chrome.
- [Issue #16](https://github.com/galacticWonder/tabsontabs_public/issues/16): Added [keyboard shortcuts](keyboard-shortcuts.md) to move between windows & filters for efficiency.
- [Issue #27](https://github.com/galacticWonder/tabsontabs/issues/27): Highlight active tab in each window
- [Issue #19](https://github.com/galacticWonder/tabsontabs_public/issues/19): Enhanced search to search by tab URL
- [Issue #7](https://github.com/galacticWonder/tabsontabs_public/issues/7): Double-click window name to go to active tab within the window
- [Issue #7](https://github.com/galacticWonder/tabsontabs_public/issues/7): Double-click window bar to open a new window

### Bug fixes
- [Issue #18](https://github.com/galacticWonder/tabsontabs_public/issues/18): Fixed issue with tabs page displaying on large monitors
- [Issue #24](https://github.com/galacticWonder/tabsontabs_public/issues/24): Fixed issue when moving pinned tab to new window
- [Issue #23](https://github.com/galacticWonder/tabsontabs_public/issues/23): Fixed issue with Tabs Left Open chart not refreshing after tab closed/opened in a new day
- [Issue #26](https://github.com/galacticWonder/tabsontabs/issues/27): Fixed issue with window name not saving when removed on startup
- [Issue #29](https://github.com/galacticWonder/tabsontabs/issues/29): Fixed issue where window recently opened and then closed is still selected. 

### Notes
- Keyboard shortcuts are documented in `keyboard-shortcuts.md`.
